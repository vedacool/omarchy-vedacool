First tagged release of my modular Omarchy (Hyprland) setup — a Gundam 00 / VEDA themed desktop you can restore piece by piece.

**Install (one line):**
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/vedacool/omarchy-vedacool/main/install.sh)
```
Or check compatibility first, change nothing:
```bash
curl -fsSL https://raw.githubusercontent.com/vedacool/omarchy-vedacool/main/install.sh | bash -s -- --check
```

**What's inside (pick-and-choose modules):**
- Gundam 00 / VEDA themes, animated desktop HUD (live CPU/temp/fan/net), screensaver, Plymouth boot splash
- Windows-like Hyprland (float-by-default, snap, SUPER+M/N, auto-hide dock)
- Bar plugins: netspeed, network, monitor, zoom-controls
- Per-process **NET MONITOR**, audio jack **plug/unplug notifications**, Chrome software-WebGL (Tinkercad), AbiWord as default text editor
- Sleep/hibernate + wifi-resume fixes, dock pins, desktop entries
- A **post-update self-heal hook** that re-applies everything after `omarchy update`

Every module is idempotent, backs up before editing, and is gated behind a dependency + compatibility **preflight** — nothing changes unless it passes and you confirm.
